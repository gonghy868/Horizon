## [JetSpec: Up to 9.64x LLM Speedup via Parallel Tree Drafting](https://www.reddit.com/r/LocalLLaMA/comments/1ufntl5/research_jetspec_speculative_decoding_with/) ⭐️ 9.0/10

JetSpec introduces causal parallel tree drafting for speculative decoding, achieving up to 9.64x lossless speedup on MATH-500 and 4.58x on open-ended chat, with over 1000 tokens per second on a single B200 GPU. This breakthrough significantly reduces LLM inference latency, making real-time applications more feasible and lowering deployment costs, while preserving output quality losslessly. JetSpec trains a causal parallel draft head over fused hidden states from the frozen target model, producing candidate trees whose scores align with the target model's autoregressive factorization, and uses CUDA graph and kernel optimizations to achieve high throughput.

reddit · r/LocalLLaMA · /u/No_Yogurtcloset_7050 · Jun 25, 21:55

**Background**: Speculative decoding accelerates LLM inference by using a small draft model to propose multiple tokens, which a larger target model verifies in one forward pass. Previous methods faced a trade-off between drafting cost and quality: autoregressive draft heads preserve causality but grow costly with depth, while block-diffusion heads draft cheaply but can produce inconsistent trees. JetSpec resolves this by drafting a causality-preserving tree in a single pass.
